# PautangBai Color Palette

Use colors consistently through shared theme tokens. Avoid sprinkling raw hex values throughout components.

| Token         | Hex       | Usage                                    |
| ------------- | --------- | ---------------------------------------- |
| `forest-900`  | `#173D35` | Primary brand, headings, strong contrast |
| `green-700`   | `#287A63` | Primary actions, links, active states    |
| `frog-400`    | `#75C99C` | Frog body and friendly illustrations     |
| `mint-300`    | `#A8DCC5` | Soft surfaces, progress highlights       |
| `paper-50`    | `#BCE9CA` | Light-mode app background (Lively Celadon) |
| `amber-500`   | `#F0B85A` | Reminders and attention accents          |
| `ink-900`     | `#252B29` | Main text                                |
| `slate-600`   | `#66716D` | Secondary text                           |
| `border-200`  | `#A6D9B6` | Borders and dividers                     |
| `white`       | `#FFFFFF` | Cards and input surfaces                 |
| `danger-600`  | `#B83D3D` | Errors and destructive actions           |
| `success-700` | `#24724F` | Successful payments and sync             |
| `warning-700` | `#94600B` | Due-soon and warning states              |

## Usage rules

- Use Forest and Bai Green for hierarchy and primary actions.
- Use Frog Green and Soft Mint for mascot artwork and low-emphasis highlights.
- Use Lively Celadon (#BCE9CA) for the light-mode canvas and White for cards.
- Reserve Amber for reminders and attention; do not use it for every accent.
- Status indicators need a text label or icon as well as color.
- Test contrast and large-text scaling on supported Android devices.

A visual swatch sheet is provided in `PAUTANGBAI_COLOR_PALETTE.svg`.
